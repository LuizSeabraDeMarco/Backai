BackAI é uma biblioteca Python para investigar o que acontece dentro de modelos de IA — observando representações, ativações, attention e como esses mecanismos evoluem enquanto o modelo aprende.

01 / The idea

Não é sobre a saída.
É sobre o caminho.

Modelos modernos nos mostram muito bem entrada e saída. O BackAI quer abrir uma janela para o espaço entre as duas — e transformar o treinamento de uma rede neural em um experimento observável.

CORE QUESTION
◉

“O que aconteceu dentro da IA para ela chegar a essa resposta?”

E, principalmente: como esse funcionamento interno surgiu e mudou durante o treinamento?

02 / Inside the model

De uma fotografia
para um filme.

Em vez de olhar apenas para o checkpoint final, o BackAI acompanha vários estados do treinamento. A pergunta deixa de ser “como funciona?” e passa a ser “como passou a funcionar assim?”.

00

Checkpoint

Salve estados do modelo em diferentes momentos do treinamento.

01

Observe

Capture ativações, representações e padrões de attention.

02

Compare

Meça como o estado interno muda entre checkpoints.

03

Relacione

Compare essas mudanças com evolução de desempenho e comportamento.

04

Intervenha

Futuramente, altere componentes internos e teste hipóteses causais.

03 / Training dynamics

Veja uma capacidade
nascer.

O objetivo não é apenas medir loss. É investigar se mudanças internas aparecem antes, durante ou depois de uma capacidade se tornar observável.

MODEL TRAINING / 100k STEPS
Step 0Representações iniciais
Step 25kAtivações começam a se reorganizar
Step 41kMudança interna detectável
Step 47kCapacidade aparece no comportamento
Step 100kModelo final
The scientific question

“A mudança interna apareceu antes do comportamento?”

04 / Research mindset

Não é “olha que legal”.
É experimento.

O projeto foi pensado para crescer como ferramenta experimental: problema → hipótese → experimento → baseline → medição → análise → repetição → conclusão.

QUESTION
# Hypothesis
A representation emerges
before the model acquires
the corresponding behavior.

if internal_change before behavior_change:
    investigate("emergence")
INTERVENTION / FUTURE
# Causal experiment
original = model(prompt)

intervene(model, component)

changed = model(prompt)

compare(original, changed)
